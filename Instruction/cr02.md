The 18–19 Nov list redesign (`876f1c9`, `b1798d1`) moved the prototype away from PRD v3 in three places. CR02 keeps the prototype's layout and puts the chips and flag where the status chip is today. The PRD should be updated to match:

| PRD v3 says | Prototype has |
| --- | --- |
| Section 6: columns Sender · Subject · Received Date · Linked Record · Action, an eye icon and a row action button (section 6.2) | An email-client list: sender (name and address), subject line with chip and attachments, date. No Linked Record column, Action column or eye icon. A row click opens the panel; actions live in the panel footer |
| Section 7: panel order AI result → Linked records → AI-filled details → Original email | AI result → Email thread → Linked records → AI-filled details |
| Not in the PRD | All emails / Unread tabs, Mark all as read, month group headers, pager with entries per page |

## 7. Dismiss and Flag again

Delete the `if(k==='other'&&e.links.length){…}` line in `runAction()` and the `if(k==='other'){…}` branch in `doAction()`. Then add:

```js
// CR02 (PRD v3 s.3.1): Dismiss follows the flag. It clears the open purpose only; links stay.
function dismissEmail(id){hideMenu();const e=find(id);if(!isFlagged(e))return;
 const sr=e.links.find(l=>l.type==='SR'&&l.status==='Open');
 if(sr){showDialog('Please confirm',confirmBox(`${sr.id} will be cancelled: no action needed. This email will no longer be flagged.`),[{label:'Cancel',run:'closeDialog()'},{label:'Dismiss',primary:true,run:`closeDialog();doDismiss(${e.id})`}]);return;}
 doDismiss(e.id);}
function doDismiss(id){const e=find(id),sr=e.links.find(l=>l.type==='SR'&&l.status==='Open');
 if(sr){sr.status='Cancelled';if(srRegistry[sr.id])srRegistry[sr.id].status='Cancelled';}
 e.dismissed={by:ME,date:TODAY,pending:e.pending,recommended:e.recommended};
 refresh();toast(sr?sr.id+' cancelled. Email dismissed':'Email dismissed');}
function flagAgain(id){const e=find(id),d=e.dismissed;if(!d)return;
 Object.assign(e,{pending:d.pending||'Flagged again by '+ME+'. Choose an action.',recommended:d.recommended,dismissed:null});
```
