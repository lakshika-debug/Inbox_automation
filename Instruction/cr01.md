# Inbox v2 – Implementation Guide

**Repo:** `lakshika-debug/Inbox_automation` (`index.html`, single file)
**Target design:** AI Inbox v2 prototype (Claude artifact "AI Inbox v2 Prototype") and PRD v2 – AI Email Automation, sections 2.1–2.3
**Reference build:** `inbox-v2-reference.html`, delivered with this guide. Its `<script>` block is the working reference for every behaviour below.

This guide lists what to change in the Inbox screen, its side panel, menus and pop-ups. The Work Orders / Calendar iframe module (`woModuleEncoded`, second `<script>` block) and the Profile & Account Settings layout are out of scope, apart from the two new Features toggles in step 10.

## 2. Data model

### 2.1 Replace the email fields

Remove `type`, `status`, `linked`, `confidence` and the per-type fields (`invoice`, `strata`, `lot`, `category`, `priority`, `description`) from each email object. Use:


## 4. Table

1. Remove the Type `<th>` and its `<col>`. Suggested widths: Sender 16%, Subject 30%, Received 13%, Status 10%, Linked Record 15%, Action 16%.
2. Rename the last header to **Action**.
3. Status cell: `badge(statusOf(e))`.
4. **Linked Record cell**:

```js
function chip(l){
  return `<a href="#" class="rec" onclick="event.preventDefault();event.stopPropagation();openRecord('${l.id}')">
    <span class="rt rt-${l.type}">${l.type}</span>${l.id}
    <span class="role">· ${l.from ? 'from '+l.from : l.role}</span></a>`;
}
function recordCell(e){
  const v = visibleLinks(e);
  if(!v.length) return '–';
  return `<span class="recs">${chip(v[0])}${v.length>1
    ? `<button class="plus" onclick="event.stopPropagation();openPanel(${e.id},'links')">+${v.length-1}</button>` : ''}</span>`;
}
```

`openRecord(id)` opens the existing record dialog: `showSRDetails` for SR IDs, the existing `viewWO` dialog for WO IDs, and a matching QR dialog for QR IDs.

5. **Action cell**:

```js
function actionCell(e, inPanel){
  const eye = inPanel ? '' : `<button class="row-icon" title="View email" aria-label="View email"
      onclick="event.stopPropagation();openPanel(${e.id})"><svg viewBox="0 0 24 24">${GLYPHS.eye}</svg></button>`;
  const drop = e.recommended
    ? `<span class="split"><button class="main" onclick="event.stopPropagation();runAction('${e.recommended}',${e.id})">
         <span class="spark">✦</span>${SHORT[e.recommended]}</button>
         <button class="more" onclick="event.stopPropagation();openActionMenu(event,${e.id},'add')" aria-label="More actions">▾</button></span>`
    : `<span class="split only"><button class="more" onclick="event.stopPropagation();openActionMenu(event,${e.id},'add')">Actions ▾</button></span>`;
  return `<div class="rowactions">${eye}${drop}</div>`;
}
const SHORT = {'create-qr':'Create QR','create-wo':'Create WO','create-sr':'Create Service Request','link-wo':'Link to WO','link-qr':'Link to QR'};
```

Rules: never put a record number inside a button. A row with no recommendation shows "Actions ▾".

## 6. Menus (reuse `#menu`)

### 6.1 Action menu – `openActionMenu(ev, id, mode, idx)`

- `mode:'add'` adds a new link; `mode:'replace'` replaces `e.links[idx]`.
- Items: Link to Work Order, Link to Quote Request, Create Quote Request, Create Work Order, Create Service Request, Mark as Other.
- Heading: "Add link", or "Replace {id} with" in replace mode.
- Tags on items:
  - `✦ Recommended` on `e.recommended`
  - `Current` (muted) on the action that matches the link being replaced
  - Create Service Request is **disabled** with "Already created" when `hasSR(e)` (rule L2)
- In add mode, hide "Mark as Other" when the email has links.
- In replace mode for an Invoice/Quote link, hide "Create Service Request".
- Positioning: reuse the existing logic (flip above when there is no room below).

### 6.2 Link row menu – `openLinkMenu(ev, id, idx)`

Heading "{id} · {role}". Items: **Open record**, **Replace with…** (opens 6.1 in replace mode), a divider, **Remove link**.

## 7. Rules engine (PRD 2.2–2.3)

```js
const BLOCKED = ['Approved','Invoice submitted','Paid','Converted'];
function blockMsg(e, l){
  if(l.type==='SR' && l.status==='Converted'){ const q = e.links.find(x=>x.from===l.id);
    return `${l.id} is now ${q.id}. Cancel ${q.id} first, then change this link.`; }
  if(l.from) return `${l.id} was created from this email. Cancel ${l.id} on its own page first; the link then closes automatically.`;
  if(BLOCKED.includes(l.status)) return `${l.id}: the ${l.role.toLowerCase()} is already ${l.status.toLowerCase()} and cannot be removed from the record.`;
  return null;
}
const removeEffect = l => l.type==='SR'
  ? `Service Request ${l.id} will be cancelled (created in error).`
  : `The ${l.role.toLowerCase()} will be removed from ${l.id}.`;
```

| User does | Behaviour |
| --- | --- |
| Pick an action in **add** mode | Run it (forms in step 8). Mark as Other when links exist → "Change not possible: remove the linked records first" |
| Pick an action in **replace** mode | If `blockMsg` → "Change not possible" dialog. Else "Please confirm": `removeEffect(link) + ' Then: ' + action`. Confirm runs the action; the old link is removed when the action completes (an SR link is set to `Cancelled` instead of removed) |
| **Remove link** | Blocked check, then confirm. On remove: if no links remain and `!e.other` → `pending:'All links removed. Choose what to do with this email.'`, `recommended:null` |
| Create Service Request | Push `SR · Request · Open`, set `pending:'Create a Quote Request or Work Order from {id}'`, `recommended:'create-qr'` |
| Submit Create QR / WO | Use the open SR link if one exists, otherwise create one in the background. Set it to `Converted`, push the new `QR`/`WO` link with `from:SR`, clear `pending` and `recommended` |
| Link to WO / QR | Push `WO · Invoice · Invoice submitted` or `QR · Quote · Received` with the chosen attachment in `docs`; clear `pending` and `recommended` |
| Mark as Other | `other:true`, clear `pending` and `recommended` |

Every manual change calls `snapshot(e)` first, then `toast(message, true)` for Undo (step 9).

## 9. Toast with Undo

```js
let prevState = null;
function snapshot(e){ prevState = JSON.parse(JSON.stringify(e)); }
function toast(msg, undo){
  const el = document.querySelector('#toast');
  el.innerHTML = `<span>${escapeHtml(msg)}</span>${undo ? '<button id="undoBtn">Undo</button>' : ''}`;
  el.classList.add('visible');
  if(undo) document.querySelector('#undoBtn').onclick = () => {
    const i = emails.findIndex(x => x.id === prevState.id); emails[i] = prevState; prevState = null;
    el.classList.remove('visible'); renderRows(); if(selected) openPanel(selected);
  };
  clearTimeout(toastHandle); toastHandle = setTimeout(() => el.classList.remove('visible'), undo ? 10000 : 3500);
}
```

Use the toast for every manual action: "SR0005 created", "QR002217 submitted", "Linked to QR002208", "Link to WO615003 removed", "Marked as Other".
